Introduction to HTML

HTML stands for Hyper Text Markup Language. It is used to create the structure of web pages.

Basic HTML Structure


<html>

<head>
<title>My Website</title>
</head>

<body>

Hello World

</body>

</html>

HTML Tags

• h1 - Heading tag
• p - Paragraph tag
• img - Image tag
• a - Link tag
• table - Table creation

Forms

Forms are used to collect user information. Example: Login forms, Registration forms.
